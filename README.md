# ছোট কাজ (ChotoKaj) — মাইক্রো জব অ্যাপ

বাংলাদেশি মাইক্রো-জব প্ল্যাটফর্ম: ব্যবহারকারীরা ছোট ছোট কাজ (Telegram জয়েন, ফলো, সাবস্ক্রাইব, ওয়েবসাইট ভিজিট) করে আয় করে; অ্যাডমিন স্ক্রিনশট প্রমাণ যাচাই করে ম্যানুয়ালি পেমেন্ট দেন (বিকাশ/রকেট/নগদ/Binance/মোবাইল রিচার্জ)।

## গঠন
- `server/` — Node.js ব্যাকএন্ড (বাইরের প্যাকেজ ছাড়া)। API + ডেটা (JSON ফাইল) + ওয়েব অ্যাপ সার্ভ করে। চালানো: `cd server && node server.js`
- `public/` — ওয়েব অ্যাপ (`index.html`) ও ডাউনলোড পেজ (`download.html`)
- `android/` — Android WebView প্রজেক্ট (APK)
- `tools/build-apk-ci.sh` — CI-তে APK বিল্ড স্ক্রিপ্ট; `.github/workflows/build-apk.yml` — GitHub Actions অটো-বিল্ড ও Release
- `DEPLOY-BN.md` — বাংলায় ধাপে ধাপে চালু করার নির্দেশনা

## নিয়ম (সার্ভারে প্রয়োগ হয়)
- রেজিস্ট্রেশন: ফোন নম্বর অথবা Gmail; টেম্প মেইল ব্লক; SMS OTP নেই; ফোন-অ্যাকাউন্টে রিকভারি Gmail বাধ্যতামূলক
- অ্যাডমিন: নির্দিষ্ট ফোন নম্বর দিয়ে রেজিস্টার করলেই অ্যাডমিন (env `ADMIN_PHONE` দিয়ে বদলানো যায়)
- প্রতি কাজে ৳০.১০ (অ্যাডমিন সেটিংসে পরিবর্তনযোগ্য), রেফার বোনাস ৫০%
- সব যাচাই ও পেমেন্ট ম্যানুয়াল (অ্যাডমিন প্যানেল থেকে)

লাইসেন্স: মালিকের নিজস্ব প্রজেক্ট।
